# OKF Generator Bundle

This directory is a reusable starting point for disciplined agentic-first
application development. It is intended to be copied, not consumed as the
GnuCash Pocket project's active knowledge base.

The bundle is designed for applications with:

* A pure or mostly pure policy core.
* A JVM/desktop host, browser host, or both.
* Clojure `.clj`, ClojureScript `.cljs`, and shared `.cljc` code.
* Unit tests, acceptance specifications, property tests, and independent QA.
* Swarm Forge coordination through git worktrees and committed handoffs.

Start with [index.md](index.md), then follow [copy-guide.md](copy-guide.md).
